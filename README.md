**The Toast Catapult** — a studio catalogue photograph of an impossible gadget, drawn entirely by a Python program. A cream-enamel countertop toaster ("CATAPULTA · MODEL T-1") with a spring-loaded catapult arm is caught mid-launch: a slice of toast, ghosted along its arc, flies toward the one waiting accessory, a blue-rimmed plate. `main.py` is a small deterministic raster renderer (analytic shapes, gradients, soft shadows, 2x supersampling, its own PNG encoder; stdlib only, no network) that writes a 1024x1024 `entry.png`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
